# Flood Safe Roads - Chennai

**Problem:** When a flood cuts off a neighbourhood, people can't tell which roads are still usable.

**Idea:** A web app that shows where flooding is happening and finds a safe route to a destination that avoids flooded roads.

**Pilot zone:** Chennai, using the December 2023 flood event.

**Built with (all open-source):** Leaflet, OpenStreetMap
